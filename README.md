# soho-network-design-packet-tracer
A Small Office/Home Office (SOHO) network designed in Cisco Packet Tracer featuring wired and wireless connectivity, DHCP, Internet access, and multiple departments.

About

This project was created to practice basic networking concepts, including router and switch configuration, DHCP, wireless networking, and communication between multiple departments.

Project Requirements

- One Cisco Router
- One Cisco 2960 Switch
- Three departments
- Automatic IPv4 addressing (DHCP)
- Wireless access for each department
- Communication between all devices

Network Devices

- Cisco Router
- Cisco 2960 Switch
- Wireless Access Points
- Desktop PCs
- Wireless PCs
- Tablet
- Smartphone

Services

- DHCP
- IPv4 Addressing
- Wireless Network

Network Information

- Network: 192.168.1.0/24
- Gateway: 192.168.1.1
- DNS: 8.8.8.8

Current Status

- Router configured
- DHCP configured
- Wired devices connected
- Wireless PCs connected
- Basic connectivity tested

Known Issue

The Smartphone could not connect to the configured Wireless Access Points. Other wireless devices connected successfully, so the issue appears to be a limitation of Cisco Packet Tracer rather than the network configuration.
